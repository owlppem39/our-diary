# 교환 일지 (Exchange Diary)

GitHub API를 백엔드처럼 사용하는, 둘이서(추후 더 늘릴 수 있는) 쓰는 교환 일지 웹앱입니다.
별도 서버 없이 브라우저에서 GitHub Contents API를 직접 호출해서 글/댓글/이미지를 저장합니다.

이 문서는 **사이트를 설치·배포하는 사람**을 위한 문서예요. 같이 쓸 친구에게는 `사용법.md`를 보내주세요. 윈도우 컴퓨터로 설치한다면 `README-windows.md`를 참고하세요 (전체 과정이 다시 정리되어 있어요).

## 구조 한눈에 보기

- **사이트 코드** (이 프로젝트) → **공개(public) 레포**에 두고 GitHub Pages로 배포합니다. 개인정보가 전혀 없는 정적 웹앱이라 공개해도 괜찮아요.
- **일지 데이터**(글, 댓글, 이미지) → 둘만 볼 수 있는 **private 레포**에 저장합니다. 브라우저가 각자의 개인 액세스 토큰(PAT)으로 이 레포에 직접 읽고 씁니다.
- 토큰은 그 어떤 파일에도 커밋되지 않고, 사용하는 기기의 브라우저 `localStorage`에만 저장됩니다.
- 프로필 사진은 리사이즈된 작은 이미지로 `config.json` 안에 함께 저장됩니다(별도 파일 업로드 없음).

```
config.json                    멤버 목록(이름, 색상, 프로필 사진)
index.json                     날짜별 작성자 색인 (캘린더/피드 조회 속도용)
entries/2026-09-13/minji.json  민지의 9월 13일 일지 (본문, 기분, 체크리스트, 이미지, 반응, 댓글)
entries/2026-09-13/yohan.json  요한의 9월 13일 일지
images/2026-09-13/minji-...jpg 글/댓글에 첨부된 이미지
```

**꼭 알아두세요: 함께 쓰는 사람 모두가 각자 자기 GitHub 계정으로 토큰을 발급받아야 해요.** 토큰은 비밀번호와 같은 개념이라 절대 공유하면 안 되고, 발급받으려면 먼저 데이터 레포에 **협업자(Collaborator)로 초대**되어 있어야 해요. 이 흐름은 아래 1~3단계에 순서대로 정리되어 있습니다.

## 사이트 이름 바꾸기

배포하기 전에 이름을 바꾸고 싶다면 `src/config.js`의 `SITE_TITLE` 값만 바꾸면 돼요. 로고와 브라우저 탭 제목에 바로 반영됩니다.

같은 파일의 `DIARY_WORD` 값을 바꾸면, 화면 곳곳에 쓰이는 "일지"라는 단어(예: "OO의 일지", "아직 쓴 일지가 없어요")도 "일기" 등 원하는 말로 한 번에 바뀝니다.

## 1. Private 데이터 레포 만들기

1. GitHub에서 새 레포를 만드세요. (예: `our-diary-data`) → **Private**로 설정.
2. 아무 파일도 미리 만들 필요 없습니다. 앱을 처음 실행하면 자동으로 `config.json`, `index.json`을 생성해요.

## 2. 같이 쓸 사람을 협업자로 초대하기

Fine-grained 토큰은 **본인이 접근 권한을 가진 레포만** 선택할 수 있어요. 그래서 레포 소유자가 아닌 사람(예: 요한)이 이 private 레포에 쓰기를 하려면, 먼저 레포에 협업자로 초대되어 있어야 해요.

1. 레포 페이지 → **Settings** → 왼쪽 메뉴 **Collaborators** → **Add people**
2. 상대방의 GitHub 아이디 또는 가입한 이메일을 입력해서 초대를 보내세요.
3. 상대방은 GitHub에서 받은 초대 메일을 열거나, GitHub 우측 상단 종모양 알림 아이콘에서 초대를 확인하고 **수락(Accept invitation)**해야 해요. 수락 전에는 다음 단계에서 이 레포가 토큰 선택 목록에 나타나지 않아요.
4. 상대방이 둘 이상이라면(멤버가 3명 이상이 될 경우) 같은 방식으로 각자 초대하면 됩니다.

## 3. 개인 액세스 토큰(PAT) 발급 — 각자 자기 계정으로 1개씩

레포 소유자를 포함해서 **사용하는 모든 사람이 각자** 아래 과정을 자기 GitHub 계정에서 진행해야 해요. (2단계에서 초대받은 사람은 초대를 수락한 뒤에 진행하세요.)

1. GitHub → 우측 상단 프로필 → **Settings** → **Developer settings** → **Personal access tokens** → **Fine-grained tokens** → **Generate new token**
2. **Repository access**: "Only select repositories" → 데이터 레포 선택 (초대를 수락한 상태여야 목록에 보여요)
3. **Permissions** → Repository permissions → **Contents: Read and write**
4. 발급된 토큰(`github_pat_...`)을 복사해두세요. (한 번만 보여줍니다)
5. 만료 기한은 편의상 1년 정도로, 또는 무기한("No expiration")으로 설정해도 괜찮아요. 만료되면 설정 → 토큰에서 로그아웃 없이 바로 갱신할 수 있어요.

> 토큰 범위를 데이터 레포 하나로만 제한해두면, 혹시 유출되더라도 다른 레포나 계정 전체에는 영향이 없어요. 내 토큰을 상대방에게 알려주지 마세요 — 각자 자기 토큰만 자기 브라우저에 입력하면 됩니다.

## 4. 사이트 코드 준비 및 로컬 실행

```bash
npm install
npm run dev
```

터미널에 아래처럼 로컬 주소가 출력돼요:

```
VITE v5.4.0  ready in 320 ms
➜  Local:   http://localhost:5173/
```

이 `http://localhost:5173/` 주소를 복사해서 크롬/사파리 등 평소 쓰는 웹 브라우저 주소창에 붙여넣고 들어가면 사이트가 열립니다.

첫 화면에서 데이터 레포 정보(소유자/레포이름)와 토큰을 입력하게 됩니다.
처음 연결하는 사람(보통 레포 소유자)이 이름, 색상, (선택) 프로필 사진을 정하면 `config.json`이 만들어지고, 두 번째 사람은 같은 레포 + 자기 토큰으로 접속해서 "새 멤버로 참여하기"를 누르면 됩니다.

## 5. GitHub Pages로 배포하기

1. 이 프로젝트를 **공개 레포**(예: `our-diary`)에 올리세요.
2. `vite.config.js`의 `base` 값을 레포 이름에 맞게 수정하세요.
   ```js
   base: '/our-diary/', // 레포 이름이 our-diary가 아니라면 바꿔주세요
   ```
3. 배포용 패키지가 이미 포함되어 있습니다:
   ```bash
   npm run deploy
   ```
   이 명령은 `npm run build` 후 `dist` 폴더를 `gh-pages` 브랜치로 올려줍니다.
4. 레포 Settings → Pages에서 소스를 `gh-pages` 브랜치로 지정하면 `https://<아이디>.github.io/our-diary/` 로 접속할 수 있어요.
5. 배포된 주소를 같이 쓸 친구에게 알려주고, `사용법.md`를 함께 전달해주세요. (친구가 아직 협업자 초대를 수락하지 않았거나 토큰이 없다면, 2~3단계부터 안내해주세요.)

## 기능

- **일지 작성**: 오늘(또는 과거 아무 날짜나 자기 칸) 일지 작성/수정/삭제. 오늘의 기분(해시태그), 본문, 사진, 체크리스트 + 수면 시간 기록
- **체크리스트 커스터마이즈**: 기본은 약/외출·운동/청소/배달 주문이고, 설정에서 항목을 자유롭게 추가하거나 뺄 수 있어요. 이 설정은 **사람마다 따로** 적용돼요 (커스텀 반응·멤버 목록과 달리 공용이 아니에요).
- **반응**: 디스코드처럼 "+ 반응 추가" 버튼을 눌러 원하는 이모지를 골라 다는 방식. 이미지를 올려서 커스텀 반응(스티커)도 직접 만들 수 있어요.
- **댓글**: 텍스트 + 사진 첨부. 업로드 전에 자동으로 리사이즈해서 레포 용량을 아낍니다.
- **캘린더 보기**(기본 화면): 위쪽 달력에서 날짜를 고르면 그 아래에 두 사람의 그날 일지가 나란히 떠요.
- **모아보기**: 사이드바에서 멤버 프로필을 누르면 그 사람 글만 최신순으로 모아볼 수 있어요. 같은 프로필을 다시 누르거나 "홈"을 누르면 캘린더로 돌아갑니다.
- **멤버 추가/삭제**: 설정에서 언제든 새 멤버를 추가하거나, 더 이상 쓰지 않는 멤버를 삭제할 수 있어요. (멤버를 삭제해도 그 사람이 이미 쓴 글은 남아있어요)
- **프로필**: 각자 설정에서 프로필 사진(직접 자르기 가능)과 테마 색·배경색을 정해서 적용할 수 있어요.

## 참고 / 한계

- 이미지는 업로드 시 가로 최대 900px, JPEG로 자동 변환/압축됩니다 (GIF는 원본 유지). 프로필 사진은 320x320으로 축소됩니다.
- 데이터는 결국 하나의 GitHub 레포이므로, 레포 용량이나 GitHub API 요청 한도(시간당 5,000회, 개인 사용에는 충분)를 신경 쓸 필요는 거의 없어요.
- 토큰은 브라우저에 평문으로 저장되므로, 공용 컴퓨터에서는 사용을 피하고 개인 기기에서만 로그인하세요.
- 글 삭제는 되돌릴 수 없어요. (GitHub 레포 히스토리에는 남지만, 앱 안에서 복구 기능은 없어요)
